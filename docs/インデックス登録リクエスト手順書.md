## STEP 0: サーチコンソール初期設定（最初に1回だけ）

### 0-1. プロパティの確認・追加

1. Google Search Console にログイン
2. 左上のプロパティ選択で `hd.jp-sing.com` があるか確認
3. なければ「プロパティを追加」→「URLプレフィックス」→ `https://hd.jp-sing.com` を入力
4. 所有権の確認 → HTMLタグ方式（サイトに認証コードは設定済み）で確認完了

### 0-2. サイトマップの送信

1. 左メニュー「サイトマップ」をクリック
2. 「新しいサイトマップの追加」に `https://hd.jp-sing.com/sitemap.xml` を入力
3. 「送信」をクリック
4. ステータスが「成功しました」になることを確認

### 0-3. TOPページのインデックス確認

1. 上部の検索バーに `https://hd.jp-sing.com` を入力 → Enter
2. 「URLはGoogleに登録されています」→ OK、STEP 1へ進む
3. 「URLがGoogleに登録されていません」→ 「インデックス登録をリクエスト」をクリック

### 0-4. 確認すべき設定項目

- [ ] 「設定」→「クロール」→ クロール頻度に問題がないか確認
- [ ] 「設定」→「ユーザーと権限」→ 必要なメンバーがアクセスできるか確認
- [ ] 「ページ」→ インデックス登録の状況・エラーがないか確認
- [ ] 「ウェブに関する主な指標」→ Core Web Vitals に問題がないか確認

## STEP 1: URLのインデックス登録リクエスト

### 操作手順（1URLごとに繰り返す）

1. Google Search Console を開く
2. 上部の検索バーに URL を貼り付け → Enter
3. 「URL検査」結果が表示される
4. 「インデックス登録をリクエスト」をクリック
5. 処理完了を待つ（数秒〜数十秒）
6. 次のURLへ

**注意:** 1日のリクエスト上限は約10〜20件。数日に分けて実施すること。

## STEP 2: 登録後の確認作業（1〜2週間後）

### 2-1. インデックス状況の確認

1. Search Console →「ページ」を確認
2. 「インデックスに登録済み」の件数が増えているか確認
3. 「クロール済み - インデックス未登録」があれば、再度リクエスト

### 2-2. ブランドクエリの検索確認

以下のキーワードでGoogle検索し、1位に表示されるか確認する:

- [ ] `株式会社Singホールディングス`
- [ ] `Singホールディングス`
- [ ] `SingHD`
- [ ] `Singhd`
- [ ] `シングホールディングス`

**1位に表示されない場合:**
- Search Console「検索パフォーマンス」でクエリを確認
- 該当ページに当該キーワードが含まれているか再確認
- 被リンク施策（グループ会社サイトからのリンク等）を実施

### 2-3. 被リンク施策（並行して実施）

外部サイトからのリンクがあるとGoogleの発見・評価が早まる:

- [ ] singgroup.biz（株式会社Sing）→ グループ会社としてhd.jp-sing.comへリンク追加
- [ ] flytop.biz（フライトップ）→ 同上
- [ ] yumesuta.com（ゆめスタ）→ 同上
- [ ] Googleビジネスプロフィール → 会社情報として登録
