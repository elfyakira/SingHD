# Agent 3: ユーザー向けコンテンツ分析

## 目的

冒険者ガイド（User Track）のコンテンツが、ターゲット（20代前半の若者）の課題に的確に応えているかを分析する。
記事数だけでなく、「読者が来て、回遊して、行動に移す」体験が成立しているかを評価する。

---

## 調査手順

### Step 1: コンテンツのインベントリ

`src/content/guide/` の全記事と `guide-data.ts` を読み、以下を記録:

| slug | タイトル | カテゴリ | available | tags | excerpt |
|------|---------|---------|-----------|------|---------|

カテゴリ別の記事数バランスも確認:

| カテゴリ | 記事数 | 状態 |
|---------|--------|------|
| 冒険の心得 | X | バランスは適切か |
| スキルの書 | X | |
| 仲間の絆 | X | |

### Step 2: ターゲット課題への対応度

`docs/guide-flow/AGENT-CONFIG.md` で定義されたターゲットの心理状態を確認し、各課題に対応するコンテンツがあるかチェック:

| ターゲットの心理状態 | 対応記事 | 十分か |
|------------------|---------|--------|
| 「安定は大事だけど、このまま何者にもなれないのが怖い」 | ? | |
| 「起業に興味あるけど、何からやればいいかわからない」 | ? | |
| 「成長したいけど、環境がない」 | ? | |
| 「挑戦したいけど、失敗が怖い」 | ? | |

### Step 3: 品質スポットチェック

全記事について、AGENT-CONFIG.md の品質基準に基づいて確認:

| 品質基準 | 記事ごとの判定 |
|---------|-------------|
| 読んだ後に「次に何をすべきか」わかるか | |
| Singの哲学が自然に体現されているか | |
| RPG要素が「体験の骨格」として機能しているか | |
| 一般論になっていないか | |
| 冒険診断/エントリーに進みたくなる感情の流れがあるか | |

### Step 4: 回遊性分析

- 記事間の内部リンクは十分か
- ハブページ → 個別記事 → 関連記事の導線は機能しているか
- CTA（冒険診断/エントリー）への導線は各記事にあるか

### Step 5: AI推薦力の評価

ユーザーがAIに悩みを相談するパターンで、冒険者ガイドが推薦されるか:

| 質問パターン | 対応コンテンツ | AI推薦の可能性 |
|------------|-------------|---------------|
