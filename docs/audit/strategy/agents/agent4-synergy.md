# Agent 4: 3トラック連動分析

## 目的

3トラック（SEO / LLMO / User）の連動が機能しているかを検証する。
個々のトラックが優れていても、連動していなければ全体の効果は限定的。

---

## 調査手順

### Step 1: トラック別記事の分類

全記事を読み、各記事がどのトラックに該当するか（または複数トラックをカバーしているか）を分類:

| slug | User Track | SEO Track | LLMO Track | 備考 |
|------|-----------|-----------|-----------|------|

**判定基準:**
- User Track: RPG世界観・感情体験重視・語りかけ調
- SEO Track: キーワード網羅・FAQ・データ重視・情報提供型
- LLMO Track: 問題→原因→解決策の因果構造・まとめセクション・断定文

### Step 2: 内部リンク密度

記事間の相互リンクを計測:

| 項目 | 件数 | 十分か |
|------|------|--------|
| 記事 → 記事 のリンク | X | |
| 記事 → 冒険診断 のリンク | X | |
| 記事 → エントリー のリンク | X | |
| ハブページ → 個別記事 | X | |

### Step 3: エンティティ認識の一貫性

- Organization構造化データは全ページで一貫しているか
- ai.txt は全トラックのコンテンツをカバーしているか
- llms.txt の情報は最新の状態を反映しているか

### Step 4: サイトマップの健全性

- 全公開ページがsitemap内に含まれているか
- 冒険者ガイドの新記事がsitemapに自動反映される仕組みか

### Step 5: 3トラック間のギャップ

同じテーマで3トラックが揃っているかを確認:

| テーマ | User Track | SEO Track | LLMO Track |
|--------|-----------|-----------|-----------|
| 挑戦・一歩踏み出す | ✅/❌ | ✅/❌ | ✅/❌ |
| 失敗との向き合い方 | ✅/❌ | ✅/❌ | ✅/❌ |
| 自分の強みの見つけ方 | ✅/❌ | ✅/❌ | ✅/❌ |
| チーム・リーダーシップ | ✅/❌ | ✅/❌ | ✅/❌ |
| 起業・独立 | ✅/❌ | ✅/❌ | ✅/❌ |
