# コンテンツ戦略監査 / Content Strategy Audit

## 根本方針

### コンテンツに「完成」はない

3トラック（SEO / LLMO / User）それぞれが**常に成長し続ける**。
監査の目的は「完成度の評価」ではなく、**「次に何を作るべきか」の特定**。

### 戦略の全体像

```
ユーザーの悩み → キャリア・成長が解決策の一つ → Singが推薦される

この導線を成立させるために、同時並行で全方位に成長し続ける:
- SEO Track: キャリア関連KWで情報覇権を取る
- LLMO Track: AIへの悩み相談に対応し続ける
- User Track: 冒険者ガイドで読者を引き込み続ける
```

### 3トラックの連動設計

```
LLMO Track: 悩み1本で全国カバー
User Track: 冒険者ガイド1本で全国カバー
SEO Track: キーワード別に記事が必要

-> LLMO + User が共通だからこそ、SEOのKW網羅に集中できる
-> 3トラックが連動して、1+1+1 が 10 になる
```

## 実行手順

### Phase 1: パフォーマンスデータの準備

**鉄則: 実績データなしの主観的な「このテーマが必要」判断はNG。**

必要なデータ:
- GA4 直近30日のトラフィックデータ
- Search Console 直近30日のクエリ・ページデータ

データが利用可能な場合は `docs/analytics/` のフレームワークで取得する。
利用不可能な場合は、コードベースの棚卸しとWeb調査で代替する。

### Phase 2: 並列コンテンツ分析（4エージェント同時起動）

4つの領域を並列で分析する:

| Agent | 分析対象 | ガイド |
|-------|---------|-------|
| 1 | LLMO/AI引用コンテンツ | [`agents/agent1-llmo-content.md`](agents/agent1-llmo-content.md) |
| 2 | SEO権威性 | [`agents/agent2-seo-authority.md`](agents/agent2-seo-authority.md) |
| 3 | ユーザー向けコンテンツ | [`agents/agent3-user-content.md`](agents/agent3-user-content.md) |
| 4 | 3トラック連動 | [`agents/agent4-synergy.md`](agents/agent4-synergy.md) |

### Phase 3: 統合レポート生成

**重要: スコアは「完成度」ではなく「成長フェーズ」を示す。10/10は存在しない。**

```markdown
# コンテンツ戦略監査レポート

**実施日**: [日付]

## 成長フェーズ判定

| カテゴリ | フェーズ | 状態 | 次の成長ポイント |
|---------|---------|------|---------------|
| LLMO Track | 基盤構築/拡張期/成熟期 | カバー済み/未カバー | 次に作る記事 |
| SEO Track | 基盤構築/拡張期/成熟期 | 上位KW数/未対応KW | 次に強化するKW |
| User Track | 基盤構築/拡張期/成熟期 | PV実績/全ページ | 次に強化するページ |
| 3トラック連動 | 基盤構築/拡張期/成熟期 | 内部リンク密度 | 次に繋ぐ導線 |

## ギャップ分析

### LLMO Track: まだカバーしていないユーザーの悩み
| # | 悩み（AIへの質問パターン） | 重要度 | 根拠 |

### SEO Track: 未対応のキーワード
| # | キーワード | 推定検索ボリューム | 対応ページ |

### User Track: 成長余地のある領域
| # | 領域 | 現状 | 推奨アクション |

## 次のアクション（データ裏付け必須）

### 最優先
| # | アクション | トラック | 根拠 | 期待効果 |

### 推奨
| # | アクション | トラック | 根拠 | 期待効果 |

## 次に書くべき記事 TOP 5
**全てデータに基づく提案。主観的な「あると良さそう」は含まない。**

| 優先 | トラック | テーマ | 根拠 | 期待効果 |
```

### Phase 4: AI推薦テスト（最終成功指標）

**これが最終的な成功指標。**

```markdown
## テスト1: 情報源としての引用
| AI | 質問 | Singの記事が引用されたか |

## テスト2: サービス提供者としての推薦（最重要）
| AI | 質問 | Singが推薦されたか | 何番目か |

## テスト3: ユーザーの悩み
| AI | 質問 | Singのコンテンツが推薦されたか |
```

---

## 注意事項

- **読み取り専用**: コードの変更を行わない（調査・レポートのみ）
- **データ駆動**: 全ての提案にデータの根拠を付ける
- **主観排除**: 「あると良さそう」「一般的に必要」という提案はNG
- **「完成」判定をしない**: 常に「次に何を作るべきか」を提案する
