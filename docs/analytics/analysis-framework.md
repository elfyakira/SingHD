# 分析フレームワーク / Analysis Framework

データ取得後、以下のフレームワークに沿って分析を行う。

---

## 分析の流れ

```
1. ビジネスファネル分析（最重要・最初にやる）
   ↓ 「どこが詰まっているか」を特定
2. 鳥の目（全体俯瞰）
   ↓ 成長しているか、構造は健全か
3. 虫の目（焦点・深掘り）
   ↓ ファネルの詰まりの原因を深掘り
4. 魚の目（時流・変化）
   ↓ 環境変化・新しい兆候
5. ACTION決定（1-3個に絞る）
   → 必ずファネルの詰まりに対応するアクションにする
```

**鉄則: ACTIONはファネルの詰まりに直結するものだけ。「改善できそう」ではなく「ビジネスに効く」で選ぶ。**

---

## 1. ビジネスファネル分析

### SingHDリクルートサイトのファネル

```
認知（Google検索表示 + AI推薦）
  ↓
流入（サイト訪問 = GA4 active users）
  ↓
関心（冒険者ガイド閲覧 / 回遊 = PV/session）
  ↓
行動（冒険診断 / エントリー）
```

### 手順

| 段階 | 指標 | データソース |
|------|------|------------|
| 認知 | 検索表示回数 | Search Console |
| 流入 | アクティブユーザー数 | GA4 |
| 関心 | 冒険者ガイドPV、PV/session | GA4 |
| 行動 | 冒険診断開始数、エントリー数 | GA4 |

### 分析ポイント

- **最大の落差はどこか？** — 段階間の転換率を計算し、最も落ちている箇所を特定
- **前月比でどの段階が変わったか？** — 改善/悪化した段階を特定
- **開発者アクセスの除外** — 自分のアクセスが含まれていないか確認

### 出力

```markdown
## ビジネスファネル

| 段階 | 今月 | 前月比 | 転換率 |
|------|------|--------|--------|
| 認知（検索表示） | ○ | — | — |
| 流入（訪問） | ○ | — | ○→○ = ○% |
| 関心（ガイドPV） | ○ | — | ○→○ = ○% |
| 行動（診断/エントリー） | ○ | — | ○→○ = ○% |

**ボトルネック**: [最も転換率が低い段階]
```

---

## 2. 鳥の目（全体俯瞰）— サイトは成長しているか？

### 見る指標

| 指標 | データソース | 問い |
|------|------------|------|
| アクティブユーザー数 | GA4 | 前月比で成長しているか？ |
| 新規率 | GA4 | 新しいユーザーが来ているか？ |
| 回遊率（PV/セッション） | GA4 | コンテンツに興味を持っているか？ |
| 直帰率 | GA4 | 期待外れで帰っていないか？ |
| 流入チャネル比率 | GA4 | 特定チャネルに依存しすぎていないか？ |
| デバイス構成 | GA4 | モバイル優位か？（ターゲットは20代→スマホ主体） |

### 分析ポイント

- **デバイス構成**: 20代ターゲットならモバイル70%以上が正常
- **流入チャネルの偏り**: 1チャネル70%以上は危険。分散が健全
- **前月比**: 2回目以降はトレンドを重視。単月の絶対値より変化率

---

## 3. 虫の目（焦点・深掘り）— ファネルの詰まりの原因は？

ファネル分析で特定したボトルネックに応じて、深掘り対象を選ぶ。

### パターンA: 認知→流入が少ない場合

| 指標 | データソース | 問い |
|------|------------|------|
| ターゲットKWの表示回数 | Search Console | そもそも検索結果に出ているか？ |
| ターゲットKWのCTR | Search Console | 順位の割にクリックされていないか？ |
| title/description の魅力 | ページ確認 | クリックしたくなるか？ |

### パターンB: 流入→関心に進まない場合

| 指標 | データソース | 問い |
|------|------------|------|
| ランディングページの直帰率 | GA4 | 読んで満足して帰っていないか？ |
| 冒険者ガイドへの導線 | ページ確認 | トップページからガイドへの動線があるか？ |
| 記事間の内部リンク | コード確認 | 次に読みたい記事が提示されているか？ |

### パターンC: 関心→行動に至らない場合

| 指標 | データソース | 問い |
|------|------------|------|
| 冒険診断への到達数 | GA4 | 診断ページまで来ているか？ |
| エントリーフォームの到達数 | GA4 | フォームまで来ているか？ |
| CTAの設置状況 | コード確認 | 各記事にCTAが適切に配置されているか？ |

---

## 4. 魚の目（時流・変化）— 潮目が変わっていないか？

| 指標 | データソース | 問い |
|------|------------|------|
| AI経由の流入推移 | GA4 referral | LLMO施策は効いているか？ |
| 新たにランクインしたKW | Search Console | 新しい検索ニーズが生まれていないか？ |
| 季節性 | 業界知識 | 就活シーズン（3-6月, 9-11月）との関係は？ |

### 分析ポイント

- **AI流入は「0か、0でないか」が重要** — 絶対数よりも存在の有無
- **季節性を無視しない** — 就活シーズンは流入増が自然
- **新KWは「意図しないもの」に注目** — 狙っていないKWでランクインしていたら、新しい需要の兆候

---

## 5. ACTION決定

### ルール

1. **最大3個**に絞る
2. **ファネルのボトルネックに直結する**ものだけ選ぶ
3. 各ACTIONに以下を明記する:
   - 現状の数値
   - 目標の数値
   - 具体的にやること
   - 期待効果

### ACTIONの優先度判断

```
即効性（すぐ効果が出る）× インパクト（ファネルへの影響度）

高即効・高インパクト → 最優先
高即効・低インパクト → 余力があれば
低即効・高インパクト → 今月着手、来月効果確認
低即効・低インパクト → やらない
```

### 出力

```markdown
## 今月のACTION

### ACTION 1: [タイトル]（即効性: S/A/B）
- **ファネル段階**: [どの段階の改善か]
- **現状**: [数値]
- **目標**: [数値]
- **やること**: [具体的な作業]
- **期待効果**: [定量的に]
```
