## ターゲット定義

### メインターゲット
**20代前半（20-26歳）の若者。起業・挑戦・自己成長に関心がある。**

- 大企業の安定よりも「自分で人生を切り拓く」側に惹かれる
- 漠然と「何かしたい」「このままでいいのか」と感じている
- まだ具体的な行動に踏み出せていない人が多い
- SNS・AI検索で情報を得る世代

### ターゲットの心理状態
- 「安定は大事だけど、このまま何者にもなれないのが怖い」
- 「起業に興味あるけど、何からやればいいかわからない」
- 「成長したいけど、環境がない」
- 「挑戦したいけど、失敗が怖い」

### ターゲットが検索しそうなキーワード
- 20代 キャリア 挑戦
- ベンチャー 成長環境
- 起業 最初の一歩
- 若手 リーダーシップ
- 仕事 やりがい 見つけ方
- 安定 vs 挑戦

## ブランドボイス

### 世界観
SingHDリクルートサイトはRPG（ロールプレイングゲーム）の世界観で構築されている。
人生 = 冒険。仕事 = クエスト。成長 = レベルアップ。仲間 = パーティ。

**ただしRPG要素は「装飾」ではなく「体験」として機能させる。ゲーム用語を散りばめるだけでは意味がない。**

### 根幹の哲学
- **「人生を、歌え。」** — 自分の人生の主人公として生きろ
- **「完璧でなくていい。まだ何者でもなくていい。」** — 挑戦のハードルを下げる
- **「失敗は経験値」** — 失敗を肯定する文化
- **「一人じゃない。仲間がいる。」** — チームで挑む

### 口調ルール
- **見出し:** 語りかけ調。読者に問いかける。「〜ではないか？」「〜だろうか」
- **本文:** です/ます体。ただし堅くしすぎない。20代が「自分に語りかけられている」と感じる温度感
- **RPG比喩:** 自然に文脈に溶け込む形で。取って付けたような「レベルアップ！」は禁止
- **英語カッコ:** セクション見出しに英語サブタイトル可（例: "## 最初の武器 — First Weapon"）

### 文体の例

**OK:**
> あなたは今、何レベルだろうか。
> レベル1でも構わない。大事なのは、経験値を積む場所を選ぶことだ。

**NG:**
> レベルアップしよう！失敗しても大丈夫！チャレンジ精神が大事です！
> （← テンションだけで中身がない。具体性がない）

**OK:**
> Singホールディングスには、入社1年目で事業責任者を任された人がいる。
> 特別な人だからではない。「やります」と手を挙げたからだ。

**NG:**
> 当社は若手に裁量を与えます。成長できる環境が整っています。
> （← 採用サイトのテンプレ。誰でも書ける）

## 品質基準

コンテンツが完成したら、以下の問いに全てYesと言えること。

1. **20代前半の読者が、読んだ後に「次に何をすべきか」わかるか？**
2. **Singの哲学（人生を歌え・失敗は経験値・仲間と挑む）が自然に体現されているか？**
3. **RPG要素が「装飾」ではなく「体験の骨格」として機能しているか？**
4. **「どこの採用サイトにもありそうな一般論」になっていないか？**
5. **読者が冒険診断 or エントリーに進みたくなる感情の流れがあるか？**

## 構成パターン

### パターン1: マインドセット型（冒険の心得向け）
```
1. フック（読者の悩み・問いかけ）
2. 視点の転換（RPG比喩で新しい見方を提示）
3. Singの事例 or 具体的な行動指針
4. まとめ（次の一歩を明確に）
5. CTA（冒険診断 / エントリー）
```

### パターン2: ハウツー型（スキルの書向け）
```
1. 課題の提示（ターゲットが直面している壁）
2. 解決のフレームワーク（3-5ステップ）
3. 各ステップの詳細（データ or 事例付き）
4. よくある失敗パターン
5. まとめ + CTA
```

### パターン3: カルチャー型（仲間の絆向け）
```
1. 組織・チームに関する問いかけ
2. Singの実例（具体的なエピソード）
3. そこから導かれる原則
4. 読者の環境への応用
5. CTA
```

## CTA・導線

### メインCTA（各コンテンツ末尾）
- **冒険診断を受ける** → `/recruit/diagnosis`
- **冒険に参加する（エントリー）** → `/recruit/entry`

### サブ導線（文中 or サイドバー）
- 関連する冒険者ガイドコンテンツへのリンク
- 挑戦者ストーリー（渡邉・飯田）への導線
- 冒険の世界（冒険マップ・冒険者タイプ等）への導線

### 導線の入れ方
- **感情が高まったポイントでCTAを置く。** 機械的に末尾に置くだけでは効果が薄い
- CTA文言はページの文脈に合わせて微調整する（テンプレ文言の使い回し禁止）

## 画像生成

### ツール
`/mnt/c/Nanobanana/generate_image_pro.py` の `generate_with_reference_pro` 関数

### スタイル
**チビ/SD（スーパーデフォルメ）スタイル。** 白背景、クリーンな線画、セルシェーディング、RPGファンタジー衣装。

### スタイル定数

```python
STYLE = (
    "Chibi / super-deformed RPG character illustration, "
    "clean line art with cel-shading, "
    "white or very light clean background, "
    "cute but professional, not overly childish, "
    "RPG fantasy clothing with modern touches, "
    "full body character standing pose, "
    "bright and cheerful color palette, "
    "consistent with Japanese mobile game character art style, "
    "no text, no watermark, no border."
)
```

### アンカー使用ルール（厳守）

1. **1つの生成画像に対して、アンカーは必ず1枚だけ渡す。** 複数アンカーを同時に渡すとスタイルが不安定になる
2. **記事の内容に合ったキャラクターを選ぶ。** テーマとキャラの対応に根拠を持たせる
3. **4キャラクターの登場回数をなるべく均等にする。** 偏りが出ないよう、キャラ選定時に過去の使用回数を確認する
4. プロンプトではアンカーのキャラクターを中心に描写し、**記事テーマを反映したシチュエーション**を追加する

### キャラクター選定の目安

| 記事テーマ | 推奨キャラ | 理由 |
|-----------|-----------|------|
| 挑戦・一歩踏み出す系 | 勇者/冒険者 | 冒険に飛び出す意志を象徴 |
| スキル・武器・装備系 | 戦士 | 武器・装備と直結 |
| 知識・学び・分析系 | 賢者 | 知恵・洞察を象徴 |
| チーム・仲間・支え合い系 | 僧侶/ヒーラー | 絆・支えを象徴 |

### 出力先
```
/mnt/c/singhd/public/img/recruit/guide/[slug].png
```

### アスペクト比
- **サムネイル**: `3:2`（ハブページのカード用）
- **記事ヒーロー**: `16:9`（記事ページ上部用。サムネと共用でも可）

### 命名規則
`[slug].png` — guide-data.tsのslugと一致させる

### バッチスクリプトの書き方（例）

```python
import os, sys, time
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from generate_image_pro import generate_with_reference_pro

STYLE = (
    "Chibi / super-deformed RPG character illustration, "
    "clean line art with cel-shading, "
    "white or very light clean background, "
    "cute but professional, not overly childish, "
    "RPG fantasy clothing with modern touches, "
    "full body character standing pose, "
    "bright and cheerful color palette, "
    "consistent with Japanese mobile game character art style, "
    "no text, no watermark, no border."
)

ANCHORS = r"C:\singhd\docs\guide-flow\anchors"
OUTPUT  = r"C:\singhd\public\img\recruit\guide"

# 1記事 = 1アンカー。複数アンカーは使わない
IMAGES = {
    "slug-name": {
        "anchor": os.path.join(ANCHORS, "hero-adventurer.jpg"),  # ← 1枚だけ
        "prompt": f"{STYLE} [記事テーマに合ったシチュエーション描写]",
        "ratio": "3:2",
    },
}

if __name__ == "__main__":
    os.makedirs(OUTPUT, exist_ok=True)
    for name, cfg in IMAGES.items():
        out = os.path.join(OUTPUT, f"{name}.png")
        if os.path.exists(out):
            print(f"SKIP {name}")
            continue
        print(f"Generating: {name}")
        generate_with_reference_pro(cfg["prompt"], [cfg["anchor"]], out, cfg["ratio"])
        time.sleep(3)
    print("Done!")
```
