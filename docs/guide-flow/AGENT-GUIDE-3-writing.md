# ライティングガイド — 冒険者ガイド

**このドキュメントは、執筆工程を担当するエージェントが読むもの。**
**目的: 構成案とリサーチ結果を受け取り、ターゲットが読んで動けるコンテンツを書く。**

**シリーズ設定は `AGENT-CONFIG.md` の「ブランドボイス」セクションを必ず読むこと。**

---

## このガイドの使い方

1. 執筆を始める前に、このガイドを通読する
2. **AGENT-CONFIG.md の「ブランドボイス」セクションを必ず読む**
3. 構成案（どのセクションに何を書くか）とリサーチ結果（出典付きデータ）は前工程から渡される
4. このガイドに書かれたルールは勝手に変えてはいけない
5. 迷ったら自分で判断せず、ユーザーに聞く

---

## 出力形式

**Markdown形式で執筆する。** `src/content/guide/[slug].md` にそのまま配置できる形式。

### frontmatter テンプレート

```yaml
---
title: "記事タイトル"
date: "YYYY-MM-DD"
category: "冒険の心得"
excerpt: "120文字以内の概要（meta descriptionにも使用）"
featured: false
tags: ["タグ1", "タグ2"]
readingTime: "○分"
image: "/img/recruit/guide/[slug].png"
---
```

## 数字の扱い

### 数字は文脈に埋め込む

- NG: 「起業5年以内の廃業率は○○%」（だから何？）
- OK: 「起業した人の○人に○人が5年以内に廃業する。厳しい数字だ。だからこそ、最初の冒険で経験値を積むことに意味がある」

### 年度・調査対象は必ず明記する

- OK: 「厚生労働省の2024年調査によると、20代の転職率は○○%」
- NG: 「20代の転職率は○○%です」

### 過去の日付を未来形で書かない

## 情報の見せ方

### 質問にはちゃんと答える

**構造: 質問 → 回答 → 根拠 → 読者への示唆**

NG:
> **20代で起業って早すぎない？**
> 起業の平均年齢は○○歳で、資金調達額は○○万円です。

OK:
> **20代で起業って早すぎない？**
> 早くない。むしろ、今の時代は20代で起業する人が増えている。
> ○○省の調査では、○○歳以下の創業者が全体の○○%を占めている。
> 大事なのは年齢ではなく、「経験値をどこで積んだか」だ。

### Markdownの構造を活かす

- `##` で大きなテーマ転換
- `###` でサブトピック
- `-` リストで要点整理
- `>` 引用で印象的なフレーズを際立たせる
- `**太字**` で核心部分を強調

## RPG要素の書き方

### 自然に溶け込ませる

OK:
> 最初に見つけた武器が一生の武器になるとは限らない。
> 冒険を続ける中で、自分に合った戦い方が見えてくる。

NG:
> スキルアップしてレベルを上げましょう！経験値をゲットだ！
> （← ゲーム実況のテンション。ターゲットは20代の大人）

### RPG比喩は1セクションに1つまで

詰め込みすぎると世界観が崩壊する。比喩は「ここぞ」で使う。

## 絶対禁止

### 出典のない数値・事実
- 全ての数値にはソース（調査名・発表元・年度）を付ける
- AIが知識として持っている情報を出典なしで記載してはいけない

### 推測表現
- 「一般的に」「よく言われる」「〜でしょう」「〜と思われます」は全て禁止

### テンプレ文言
- 「成長できる環境」「裁量が大きい」「風通しの良い社風」→ 具体的なエピソードに置き換える
- 「あなたの挑戦を応援します」→ 具体的に何をどう応援するのか書く
