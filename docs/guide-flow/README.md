# 冒険者ガイド コンテンツ量産フロー

**「コンテンツを増やしてください」で動く5段階パイプライン。**

---

## フロー概要

```
テーマ決定
    ↓
[GUIDE-1] リサーチ     ← WebSearch/WebFetchで裏どり
    ↓
[GUIDE-2] 構成設計     ← ユーザー承認
    ↓
[GUIDE-3] 執筆         ← Markdown出力
    ↓
[GUIDE-4] 実装         ← ファイル配置 + 画像生成 + データ登録
    ↓
[GUIDE-5] QA           ← 全チェック通過で公開
```

---

## ドキュメント一覧

| ファイル | 役割 |
|---------|------|
| `AGENT-CONFIG.md` | **全工程が参照する設定ファイル。** ターゲット・ブランドボイス・品質基準・カテゴリ・画像生成ルール |
| `AGENT-GUIDE-1-research.md` | リサーチ工程。テーマについて事実を集め、裏どりし、出典を記録 |
| `AGENT-GUIDE-2-content-design.md` | 構成設計工程。セクション構成・感情設計・CTA配置を設計 |
| `AGENT-GUIDE-3-writing.md` | 執筆工程。Markdown形式でコンテンツを書く |
| `AGENT-GUIDE-4-implementation.md` | 実装工程。ファイル配置・画像生成・データ登録 |
| `AGENT-GUIDE-5-qa.md` | QA工程。品質チェック・修正要求 |

---

## 1コンテンツ追加時に更新されるファイル

| ファイル | 内容 |
|---------|------|
| `src/content/guide/[slug].md` | Markdownコンテンツ本体 |
| `src/app/recruit/guide/guide-data.ts` | ハブページのカード情報 |
| `public/img/recruit/guide/[slug].png` | サムネイル画像 |
| `src/app/sitemap.ts` | ※動的に読み込むため手動更新不要 |
| `public/ai.txt` | AIクローラー向けコンテンツ情報 |
| `public/llms.txt` | LLM向けコンテンツ情報 |

## クイックスタート（エージェントへの指示例）

### 新しいコンテンツを1つ追加する

```
冒険者ガイドに新しいコンテンツを追加してください。
テーマ: [テーマ]
カテゴリ: 冒険の心得 / スキルの書 / 仲間の絆

docs/guide-flow/ のガイドに従って、
リサーチ → 構成設計 → 執筆 → 実装 → QA の順で進めてください。
```

### 複数コンテンツを一括追加する

```
冒険者ガイドのコンテンツを増やしてください。
docs/guide-flow/ のガイドに従って進めてください。

以下のテーマで作成:
1. [テーマ1]（カテゴリ: 冒険の心得）
2. [テーマ2]（カテゴリ: スキルの書）
3. [テーマ3]（カテゴリ: 仲間の絆）
```

---

## 注意事項

- **AGENT-CONFIG.md が全ての起点。** 変更する場合はここを先に更新する
- **カテゴリの追加はSEO/LLMOキーワード調査の結果に基づいて行う**
- **画像生成にはNanobananaツールが必要。** 詳細は `docs/NANOBANANA.md` 参照
- **sitemap.tsは guide-loader から動的にスラッグを読み込むため、Markdownを配置すれば自動でsitemapに反映される**
