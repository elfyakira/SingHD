# SEO Track CONFIG — SingHD リクルートサイト

**目的**: ターゲットがGoogleで検索したときに上位表示される記事を制作する
**配置先**: `src/content/guide/[slug].md`（冒険者ガイドと同じ配置）
**ターゲット検索エンジン**: Google / Bing / Yahoo

---

## ターゲット定義

### 誰のために書くか

**20代前半（20-26歳）がキャリアに関する情報をGoogle検索で探すとき、最初に見つかる記事**

| # | ユーザー像 | この人が必要としていること |
|---|----------|----------------------|
| 1 | 「このままでいいのか」と漠然と不安な若者 | 「20代 キャリア 挑戦」で検索 → 何から始めればいいかの具体的手順 |
| 2 | ベンチャーか大企業か迷っている就活生 | 「ベンチャー 大企業 どっち」で検索 → 判断基準と両方のリアル |
| 3 | 起業に興味あるが踏み出せない若者 | 「起業 最初の一歩 20代」で検索 → 起業前にできることの体系的な整理 |
| 4 | 自分の強みがわからない若者 | 「自分の強み わからない」で検索 → 自己分析の具体的メソッド |

### User Trackとの違い

| | User Track（冒険者ガイド） | SEO Track |
|---|---------|----------|
| 最適化対象 | 読者の感情体験 | Google検索順位 |
| 文体 | RPG世界観・語りかけ調 | 情報提供者・専門家の声 |
| 構造 | 感情の流れ重視 | キーワード網羅・FAQ |
| CTA | 冒険診断/エントリー | 同じだが、より自然に（情報の延長線上で） |

**同じテーマで別記事として共存する。** 情報に矛盾がなければ両方あってよい。

## 品質基準

以下の全てにYesと言えなければ出す価値がない。

1. **ターゲットがこの記事を読んで「具体的に何をすればいいか」わかるか？**
2. **データと出典に基づいた信頼できる内容か？**（感想文ではなく実務資料として使えるか）
3. **狙いキーワードの検索意図に正確に答えているか？**
4. **読了後に「この発信元はキャリアの専門性がある」と感じるか？**

## 文体設計

### 2つの声

| 場所 | 誰の声 | 口調 | 例 |
|------|--------|------|-----|
| 見出し | 読者の疑問 | 簡潔で直接的 | 「ベンチャーと大企業、どっちが成長できる？」「起業前にやるべき3つのこと」 |
| 本文 | 専門家の声 | ですます調、信頼感のあるトーン | 「実際のデータを見てみましょう。○○調査によると...」 |

### 文体の温度感

- **RPG比喩は使わない**（User Trackとの差別化。SEO Trackは情報の信頼性で勝負する）
- **営業トーク禁止**。あくまで情報提供者の立場
- **曖昧な表現禁止**。数字と出典で語る
- **結論を先に**。検索ユーザーは結論から読む

### 数字の翻訳例

- 「新卒3年以内離職率32.3%」→「約3人に1人が3年以内に離職。つまり入社前の情報収集が決定的に重要」
- 「起業5年生存率18.3%」→「5年後に残っている会社は約5社に1社。だからこそ準備段階が勝負を分ける」

## 構成パターン

### パターンSEO-1: 情報提供型（標準）

| 順序 | セクション | 目的 |
|------|----------|------|
| 1 | ヒーロー | キーワードを含むh1 + 「この記事でわかること」 |
| 2 | 全体像/概要 | テーマの全体像を簡潔に提示 |
| 3-6 | 本文セクション群 | 具体的な知識をSTEP by STEPで |
| 7 | FAQ | 関連する疑問に回答（FAQ Schema対応） |
| 8 | CTA + 出典 | Singへの自然な導線 + 出典一覧 |

### パターンSEO-2: 比較/解説型

| 順序 | セクション | 目的 |
|------|----------|------|
| 1 | ヒーロー | 比較テーマのh1 |
| 2 | なぜ比較が必要か | 判断を間違えるとどうなるか |
| 3 | 比較表 | 選択肢を表形式で一覧化 |
| 4-6 | 各選択肢の詳細 | それぞれの詳細・メリデメ |
| 7 | 判断基準 | どの状況でどれを選ぶべきか |
| 8 | CTA + 出典 | |

## CTA・導線

### 導線の入れ方

記事本文中にSingを直接売り込まない。あくまで「選択肢のひとつ」として自然に登場させる。

- OK: 「起業前に実務経験を積みたいなら、若手に裁量を渡すスタートアップで経験を積む方法もあります」
- NG: 「Singなら最高の成長環境が待っています！今すぐエントリー！」

### メインCTA（各コンテンツ末尾）
- **冒険診断を受ける** → `/recruit/diagnosis`
- **冒険に参加する（エントリー）** → `/recruit/entry`
