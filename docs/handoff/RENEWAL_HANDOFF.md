## 🚀 サービス詳細: ミライク

### 基本情報

| 項目 | 内容 |
|------|------|
| サービス名 | ミライク |
| 対象年齢 | 22〜35歳 |
| 対象者 | 本気で挑戦する人 |
| 支援期間 | 6ヶ月〜1年 |
| 費用 | 詳細は面談時に提示 |

### 支援内容

- 事業設計
- 収益モデル構築
- 法人設立支援
- 営業支援
- マーケティング支援
- 資金計画サポート

### 支援の流れ（4ステップ）

1. **無料相談** - まずは話を聞く
2. **事業設計・市場検証** - アイデアを形にする
3. **収益モデル構築** - 稼ぐ仕組みを作る
4. **実行・伴走支援** - 一緒に走る

### グループ会社への参画

**参画形態**:
- 新規事業立ち上げ
- 経営幹部候補
- 事業責任者

**参画メリット**:
- 給与保証
- 資金バックアップ
- 営業基盤共有
- 経営ノウハウ提供

### 選ばれる5つの理由

1. 若い代表によるリアルな挑戦環境
2. 実行基盤が整っている
3. 伴走型支援
4. 営業・マーケ支援が強い
5. 実践主義
