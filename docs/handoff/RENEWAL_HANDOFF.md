## 🚀 サービス詳細: ミライク

### 基本情報

| 項目 | 内容 |
|------|------|
| サービス名 | ミライク |
| 対象年齢 | 22〜35歳 |
| 対象者 | 本気で挑戦する人 |
| 支援期間 | 6ヶ月〜1年 |
| 費用 | 詳細は面談時に提示 |

### 支援内容

- 事業設計
- 収益モデル構築
- 法人設立支援
- 営業支援
- マーケティング支援
- 資金計画サポート

### 支援の流れ（4ステップ）

1. **無料相談** - まずは話を聞く
2. **事業設計・市場検証** - アイデアを形にする
3. **収益モデル構築** - 稼ぐ仕組みを作る
4. **実行・伴走支援** - 一緒に走る

### グループ会社への参画

**参画形態**:
- 新規事業立ち上げ
- 経営幹部候補
- 事業責任者

**参画メリット**:
- 給与保証
- 資金バックアップ
- 営業基盤共有
- 経営ノウハウ提供

### 選ばれる5つの理由

1. 若い代表によるリアルな挑戦環境
2. 実行基盤が整っている
3. 伴走型支援
4. 営業・マーケ支援が強い
5. 実践主義

### TOPページ 仕様

**ファイル**: `src/app/page.tsx`
**方針**: 大幅に作り直す

#### セクション構成（上から順）

1. **ヒーロー**
   - 背景: ダーク（黒系）
   - メインコピー: 「夢を、ビジネスに。」
   - サブコピー: 「起業という選択を、もっと現実的に。」
   - CTA: 無料相談を予約する
   - デザイン: 大きなタイポグラフィ、余白多め

2. **ミライク概要**
   - サービス名「ミライク」の紹介
   - 一言説明
   - 詳細ページへのリンク

3. **3つのメリット（選ばれる理由）**
   - 3つに絞って表示
   - アイコン or 数字 + テキスト
   - 簡潔な説明

4. **支援の流れ**
   - 4ステップを視覚的に表示
   - ステップ番号 + タイトル + 簡単な説明

5. **代表メッセージ**
   - 代表写真
   - メッセージ: 「起業は才能ではなく、環境で決まる。挑戦する人が孤立しない社会をつくりたい。」
   - 代表名・肩書

6. **無料相談CTA**
   - 「まずは話を聞いてみませんか？」
   - ボタン: 無料相談を予約する
   - 補足: オンライン・対面対応 / 60分 / 代表が直接対応
