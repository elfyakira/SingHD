# 月次分析

GA4 / Search Console のデータに基づく月次パフォーマンス分析。
ビジネスファネル起点で「何が詰まっているか」を特定し、ACTIONを決定する。

---

## 手順

**まず `docs/analytics/analysis-framework.md` を読み込むこと。**

### Step 1: データ収集

以下のデータをユーザーに依頼する（または利用可能なデータを確認）:

#### GA4データ（直近30日）
- アクティブユーザー数（新規/リピーター）
- ページビュー（全体 + 冒険者ガイド）
- PV/セッション
- 流入チャネル別（Organic / Direct / Referral / Social）
- デバイス構成（Mobile / Desktop / Tablet）
- 冒険診断ページへの到達数
- エントリーページへの到達数

#### Search Consoleデータ（直近30日）
- 表示回数上位クエリ（上位50件）
- クリック数上位ページ（上位20件）
- 平均掲載順位

データが手元にない場合は、取得方法を案内する。

### Step 2: ファネル分析（最重要）

```
認知（検索表示） → 流入（訪問） → 関心（ガイドPV） → 行動（診断/エントリー）
```

各段階の数値を埋め、転換率を計算。**最大の落差がボトルネック。**

### Step 3: 鳥の目（全体俯瞰）

前月比での成長率、流入チャネル構成、デバイス構成を確認。

### Step 4: 虫の目（深掘り）

ボトルネックの原因をデータで特定:
- 認知が弱い → Search Consoleで表示回数・順位を深掘り
- 流入→関心が弱い → 直帰率・導線を確認
- 関心→行動が弱い → CTA設置状況を確認

### Step 5: 魚の目（時流）

- AI経由の流入はあるか
- 新しくランクインしたKWはあるか
- 就活シーズンとの関係

### Step 6: ACTION決定

**最大3個。ファネルのボトルネックに直結するものだけ。**

各ACTIONに: 現状数値 / 目標数値 / 具体的作業 / 期待効果

---

## 出力フォーマット

```markdown
# SingHD 月次分析レポート — YYYY年MM月

## ビジネスファネル
| 段階 | 今月 | 前月比 | 転換率 |
**ボトルネック**: [特定された段階]

## 鳥の目（全体俯瞰）
- トラフィック概況
- 流入チャネル構成
- デバイス構成

## 虫の目（深掘り）
[ボトルネックの原因分析]

## 魚の目（時流）
- AI流入状況
- 新規KW
- 季節性

## 今月のACTION
### ACTION 1: [タイトル]
- ファネル段階: [どの段階]
- 現状: [数値]
- 目標: [数値]
- やること: [具体的]
- 期待効果: [定量的]
```

---

## 注意事項

- **読み取り専用**: コードの変更を行わない
- **データがなければ聞く**: 推測でファネル数値を埋めない
- **前月レポートがあれば比較**: ACTIONの効果検証を含める
