# SingHD SEO/LLMO コンテンツ戦略監査

SingHDリクルートサイト（hd.jp-sing.com）に特化した包括的なSEO/LLMO監査を実行する。
技術的なSEOチェックに加え、**ターゲットの検索行動・AI質問パターンに基づくコンテンツ戦略提案**を行う。

---

## ターゲット定義（固定）

- **メインターゲット**: 20代前半（20-26歳）。起業・挑戦・自己成長に関心がある若者
- **サブターゲット**: 新卒・第二新卒・スタートアップ志向の学生
- **心理状態**: 「安定は大事だけど、このままでいいのか」「挑戦したいけど怖い」
- **主要デバイス**: スマートフォン

---

## 監査手順

### Phase 1: 現状把握（並列実行 — 5エージェント）

#### Agent 1: 技術SEO監査
```
subagent_type: Explore

チェック項目:
- 全page.tsx/layout.tsxのメタデータ（title, description, openGraph, twitter）
- canonical URL設定
- 構造化データ（JSON-LD/Schema.org）の実装状況
- sitemap.tsの網羅性（全公開ページが含まれているか）
- robots.txtのAIクローラー許可設定
- next.config最適化（画像、圧縮、バンドル）
- Imageコンポーネントの最適化（sizes, priority, lazy）
- セキュリティヘッダー
- Core Web Vitals に影響する問題

出力: 技術的な問題リスト（Critical/Warning/Good）
```

#### Agent 2: LLMO対策監査
```
subagent_type: Explore

チェック項目:
- public/ai.txt の内容品質
  - 全ページが網羅されているか
  - 説明が十分か（AIが文脈を理解できるか）
  - キーワードの自然な含有
- public/llms.txt の内容品質
  - LLMが参照した際に正確な情報を返せるか
  - 企業情報・採用情報・コンテンツ情報が最新か
- セマンティックHTML（article, section, nav, header, footer, time, figure）
- 各ページの見出し構造（h1→h2→h3の階層）
- パンくずリスト（BreadcrumbList構造化データ）

出力: LLMO対策の充実度、AI回答に拾われるための改善案
```

#### Agent 3: 現行コンテンツ棚卸し
```
subagent_type: Explore

チェック項目:
- src/content/guide/ の全記事一覧と状態（available: true/false）
- guide-data.ts のカテゴリ別記事数バランス
- 各記事のSEOキーワード（tags, excerpt）の網羅性
- 各記事のCTA導線（冒険診断/エントリーへの接続）
- 記事間の内部リンク状況
- recruitセクション全ページのコンテンツ量と質
- 画像のalt属性の設定状況

出力: コンテンツ棚卸し表（ページ/記事、状態、キーワード、内部リンク数）
```

#### Agent 4: ターゲットキーワード調査
```
subagent_type: general-purpose（WebSearch使用）

調査内容:
1. メインキーワードの検索ボリューム・競合度調査
   - 「20代 キャリア 挑戦」「ベンチャー 成長環境」「起業 最初の一歩」
   - 「若手 リーダーシップ」「仕事 やりがい 見つけ方」「安定 vs 挑戦」
   - 「新卒 ベンチャー」「第二新卒 スタートアップ」「20代 転職」

2. ロングテールキーワード発掘
   - 「20代 起業 何から始める」「ベンチャー 大企業 どっち」
   - 「自分の強み わからない」「チームワーク 苦手 克服」
   - Google サジェスト・関連キーワードをWebSearchで収集

3. 競合コンテンツ調査
   - 上記キーワードで上位表示されているコンテンツの傾向
   - 競合が扱っていてSingが扱っていないテーマ

出力: キーワードリスト（メイン/ロングテール）、競合ギャップ分析
```

#### Agent 5: AI質問パターン調査
```
subagent_type: general-purpose（WebSearch使用）

調査内容:
1. ターゲットがAI（ChatGPT/Claude/Perplexity）に聞きそうな質問を推定
   - 「20代でベンチャーに入るメリット・デメリットは？」
   - 「大企業とスタートアップどっちがいい？」
   - 「自分の強みの見つけ方を教えて」
   - 「起業したいけど何から始めればいい？」
   - 「チームワークが苦手だけどどうすればいい？」
   - 「新卒でベンチャーってありえる？」

2. 各質問に対してAIがどのような情報源を参照するか調査
   - 現在のAI回答に含まれる情報源の傾向
   - SingHDのコンテンツがAI回答に含まれる可能性の評価

3. AIに拾われるためのコンテンツ要件分析
   - Q&A形式の構造が有効か
   - 出典付きデータの重要性
   - 独自性のあるコンテンツとは何か

出力: AI質問パターン一覧、AI回答に含まれるための戦略
```

---

## 注意事項

- **読み取り専用**: この監査はコードの変更を行わない（調査・レポートのみ）
- **WebSearch必須**: Agent 4, 5 は `subagent_type: "general-purpose"` を使う（Exploreにはない）
- **フォアグラウンド実行**: WebSearch系エージェントはバックグラウンドで実行しない
- **出典重視**: キーワード調査・競合分析のデータには出典を付ける
- **guide-flowとの連携**: コンテンツ追加提案は `docs/guide-flow/AGENT-CONFIG.md` のカテゴリ体系に従う
